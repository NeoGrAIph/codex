# Fork prompts

Каталог содержит поддерживаемые prompt-шаблоны для повторяющихся задач по сопровождению форка. Prompts пишутся на русском языке; upstream identifiers, commit subjects, PR ids, API/type/config/tool/wire names сохраняются на исходном языке.

| Prompt | Назначение | Когда использовать |
| --- | --- | --- |
| [Актуализация multi-agents research](research/multi-agents-update-goal.md) | Обновить `docs/fork/research/multi-agents/{timeline.md,evidence.md,architecture.md}` после выхода нового upstream stable-релиза. | Когда research-база уже создана и нужно добавить только новые stable-релизы без пересоздания истории. |
